Sobre

Ciência Conferida é um site independente de divulgação científica para quem é curioso, de criança a adulto. A ideia é simples: responder perguntas do dia a dia com uma resposta curta, uma explicação completa e a fonte de cada fato ao alcance de um clique.

Os assuntos são variados (céu, mar, corpo humano, espaço, bichos, tecnologia) porque a curiosidade também é. O que não varia é o método descrito em como fazemos.

O código do site e todos os artigos são abertos: https://github.com/Luan-Savarese/ciencia-conferida.
